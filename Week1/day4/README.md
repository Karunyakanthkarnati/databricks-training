# 📊 Week 1 - Day 4: SQL Joins Practice

## 📌 Overview
Day 4 focused on practicing SQL JOIN operations using a student-course enrollment management system.

The practice session included:
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- Handling unmatched records
- Multi-table joins
- Real-world reporting queries

This assignment helped in understanding how relational databases connect data across multiple tables.

---

# 🗂️ Database Tables Used

| Table Name | Description |
|------------|-------------|
| `students` | Stores student information |
| `courses` | Stores course details |
| `instructors` | Stores instructor details |
| `enrollments` | Stores student enrollment records |
