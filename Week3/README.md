# 🚀 Week 3 – PySpark Fundamentals

## 📖 Overview

This week focused on building a strong foundation in PySpark by learning how to read and write data, manage schemas, create DataFrames, perform basic DataFrame operations, and work with commonly used file formats such as CSV, JSON, and Parquet.

---

## 📅 Topics Covered

### ✅ Day 1 – Reading CSV Files

* Introduction to Apache Spark
* Reading CSV files using `spark.read.csv()`
* Reading files using `format().load()`
* Header handling
* Schema inference
* Displaying DataFrames

### ✅ Day 2 – Schema Definition, Select, Alias & Sorting

* Schema inference
* Custom schema definition
* `printSchema()`
* `select()`
* `col()`
* `alias()`
* Sorting DataFrames
* Multi-column sorting

### ✅ Day 3 – Creating DataFrames

* Understanding SparkSession
* `createDataFrame()`
* Creating DataFrames from lists
* Creating DataFrames from dictionaries
* Schema inference
* StructType & StructField
* Manual schema creation

### ✅ Day 4 – Reading CSV with Custom Schemas

* Reading CSV files using different approaches
* Reading multiple files
* String-based schema definition
* StructType-based schema definition
* Applying custom schemas
* Schema inspection

### ✅ Day 5 – Writing DataFrames to CSV

* Writing DataFrames using `df.write.csv()`
* Writing using Data Source API
* Write modes (`overwrite`, `append`, `ignore`, `error`)
* Reading written CSV files
* Understanding Spark output files and partitions

### ✅ Day 6 – Reading & Writing JSON and Parquet

* Reading JSON files
* Reading multi-line JSON
* Reading multiple JSON files
* Writing DataFrames to JSON
* Reading Parquet files
* Writing DataFrames to Parquet
* Verifying written Parquet data
